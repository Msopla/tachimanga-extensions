# Extensiones de Msopla para Tachimanga

Extensiones en español de **LectorXD, ManhwaShot y Olympus XYZ** para Tachimanga.

## Cómo añadir el repositorio a Tachimanga

1. Copia esta dirección:

   ```text
   https://raw.githubusercontent.com/Msopla/tachimanga-extensions/main/index.min.json
   ```

2. En Tachimanga, ve a la sección de **repositorios de extensiones** y pega la dirección.
3. Abre **Explorar → Extensiones**, desliza hacia abajo para actualizar la lista e instala las extensiones que quieras.
4. Cuando salga una versión nueva, aparecerá el botón **Actualizar** en la extensión.

También puedes descargar un APK de la tabla, guardarlo en **Archivos** del iPhone e importarlo desde **Explorar → Extensiones → +**.

Guías oficiales de Tachimanga: [añadir un repositorio](https://tachimanga.app/help/guides/repositories.html) e [importar un APK](https://tachimanga.app/help/guides/add-extension-file.html).

## Última actualización

- **LectorXD 1.4.3:** carga la lista completa de capítulos de cada serie, aunque la página la reparta en varias páginas.
- **ManhwaShot 1.4.3:** cada capítulo muestra su fecha real de subida (antes todos salían como "Hoy"). También lee los capítulos marcados como "gratis solo para usuarios": inicia sesión en la web desde el botón **WebView** de Tachimanga y se abrirán en la app.
- **Olympus XYZ 1.4.1:** lee el catálogo, la búsqueda, las novedades y la lista completa de capítulos de cada serie, con su fecha y el grupo que lo tradujo.

Si una página pide verificación de Cloudflare o iniciar sesión, ábrela con el botón **WebView** de Tachimanga, complétala y vuelve a cargar.
